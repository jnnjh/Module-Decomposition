# Workflow

1. Set up Express server
2. Configure Socket.IO for real-time communication
3. Create EJS frontend page
4. Add chat input and message display area
5. Implement username selection and localStorage persistence
6. Create Socket.IO events:
   * new_user
   * new_message
   * chat_history
   * broadcast_message
   * user_count
7. Store messages in server memory
8. Broadcast messages to all connected users
9. Display previous messages when a user joins
10. Add online user counter
11. Add timestamps to messages
12. Add Enter-to-send functionality
13. Style chat interface with CSS
14. Add middleware:
    * cors()
    * express.json()
    * express.static()
15. Test with multiple browser windows
16. Deploy application
17. Verify real-time messaging works after deployment
